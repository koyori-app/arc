# 目盛りの段と土日の帯の設計書

| 項目 | 値 |
|------|-----|
| 文書ID | `design/day-scale` |
| 関連 | `design/palette-opt-in`（この上に積む）、task の cmd_411（ガントの作り直し） |
| 状態 | 実装 |
| 基準 | `feat/gantt-palette` の `d45285e` |

## 1. 要約

使う側が、日付の見出しの目盛り（日、週、月）と一日の幅を選び、土日に帯を引けるようにする。

今の図は、月曜ごとの線と `M/D` の札だけを描き、一日は 30px に決まっている。
task のガントは、日ごとの数字と曜日、土日の地、日、週、月の切り替えを求める（cmd_405 の困り所の六と七）。

| 問い | 採る答え |
|------|---------|
| 一、目盛りの段 | `options_json` の `scale`: `"week"`（既定。今の図）、`"day"`、`"month"`（3.1） |
| 二、一日の幅 | `px_per_day`。既定は `PX_PER_DAY`（30）（3.2） |
| 三、曜日の字 | `weekday_labels`（月曜から七つ）。既定は英字の二字。arc は和文を決め打ちしない（3.3） |
| 四、土日の帯 | `weekend_days`（0 が月曜、6 が日曜）。既定は無し。色は `ColorId::Weekend`（落ち先は `HeaderBg`）（3.4） |

既定は一字も変えない。

## 2. 今の作りで確かめたこと

- x は `label_w + 日数 × PX_PER_DAY` の式で、棒、依存の矢印、今日の線、進捗の線、目盛り、札の右端、幅の計算のそれぞれに書かれていた。
- 目盛りは `grid_days`（月曜）の線と札だけで、線と札を交互に描く。出力を縛る試験はこの順を含む。

## 3. 口の形

### 3.1 `scale`

- `"week"`: 月曜に線と `M/D` の札。今の図と同じ。
- `"day"`: 月曜の線は残し、週の札の代わりに、日ごとに数字と曜日を日の欄の真ん中に描く。最初の日と月の頭の日の上に `YYYY/M`。
  月の札は見出しの上の端、数字と曜日は見出しの下の端に置くので、`header_height_px` を高くすれば間が空く（48px で三段が収まる）。
- `"month"`: 月の頭（と最初の日）に線と `YYYY/M` の札。

### 3.2 `px_per_day`

- 一日の幅。0 を越え 1000 以下の数。全ての x と幅がこれに従う。
- Canvas の上限の判定の日数の上限（`MAX_CANVAS_DATE_SPAN_DAYS`）は 30px で数えたまま。幅の判定は実際に描く幅で測るので、広い日でも上限を越える図は断られる。狭い日では日数の上限が先に効き、描けそうな長い図を断ることがある（緩む向きには動かない）。

### 3.3 `weekday_labels`

- 月曜から日曜の七つの字。各 1 から 8 字。既定は `Mo`、`Tu`、`We`、`Th`、`Fr`、`Sa`、`Su`。
- 字は SVG の他の字と同じく escape して書く。

### 3.4 `weekend_days`

- 0（月曜）から 6（日曜）の数の配列。同じ数は二度書けない。
- 指定した曜日の日ごとに、行の区画（見出しの下から最後の行まで）に一日の幅の帯（`RectSemantic::Weekend`、class `weekend`）を描く。群れの帯の上に重ね、土日が群れの見出しの行でも読めるようにする。
- 色の名 `ColorId::Weekend` を足した。既定の色の表には入れず、落ち先は `HeaderBg`。`palette` で替えられる。canvas の色の番号は 14。

## 4. 描き方

- `XAxis`（題の列の幅と一日の幅）を一つ置き、全ての x はそこから読む。式は今までと同じ順で足すので、既定の図の数は一桁も変わらない。
- 目盛りの札の右端は、描く札そのものから求める（`grid_text_of` と `day_texts` を描くのと幅を決めるのと両方で使う）。最後の日の札が図からはみ出さない。
- `ChartOptions` は曜日の字（`String`）を持つので `Copy` でなくなった（`Clone` のまま）。0.1.0-alpha の間は形を約束していない。
