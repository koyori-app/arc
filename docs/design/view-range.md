# 表示の範囲と範囲の外へ続く印の設計書

| 項目 | 値 |
|------|-----|
| 文書ID | `design/view-range` |
| 関連 | `design/bar-marks`（この上に積む）、`design/day-scale`、task の cmd_411（ガントの作り直し） |
| 状態 | 実装 |
| 基準 | `feat/gantt-bar-marks` の `348cadf` |

## 1. 要約

使う側が、図に描く日の範囲を選べるようにする。範囲を越えて続く棒は範囲の端で切り、続く先の日を `→ M/D` や `← M/D` の印で示す。

今の図は、全ての課題が入る日数を描く。
task のガントは、前と次の送り、日、週、月の切り替えで、決まった範囲だけを描く。範囲の外へ続く棒には、端に印と終わりの日を描くことを求める（cmd_405 の困り所の七、cmd_408 の困り所の六）。

| 問い | 採る答え |
|------|---------|
| 一、範囲の口 | `options_json` の `view`: `{"from": "YYYY-MM-DD", "to": "YYYY-MM-DD"}`。両端の日を含む（3.1） |
| 二、範囲を越える棒 | 範囲の端で切る。切った端の内側に、続く先の日を印で描く（3.2） |
| 三、範囲の外の課題 | 棒を描かず、外れている側の端に印だけを描く（3.3） |
| 四、他の部品 | 依存の矢印、今日の線、進捗の線、厳守の菱形、目盛りは範囲の内に留める（3.4） |

`view` を渡さぬ図は一字も変えない。

## 2. 今の作りで確かめたこと

- 図の最初の日（epoch）は、課題の始まりの最も早い日である。日数は最後の課題の終わりと、行の厳守の期日まで延びる。
- 棒の `end` は境の日で、棒はその日の前の日までを覆う。
- Canvas の上限の判定は、課題の日付の幅から日数を数える。

## 3. 口の形

### 3.1 `view`

- `from` と `to` の二つの鍵だけを持つ object。どちらも `YYYY-MM-DD` で、両端の日を含む。
- `view` を渡すと、図の最初の日は `from`、日数は `to - from + 1` 日に決まる。幅は日数と一日の幅で決まり、課題の日付では延びない。
- 断るもの（`parse_error`）: object でない値、鍵の過不足、読めない日付（時刻付きを含む）、`to` が `from` より前、3,650 日（`MAX_DATE_SPAN_DAYS`）を越える範囲。
- Canvas の上限の日数の判定は、範囲の日数で数える。長い期間の課題を持つ図でも、短い範囲なら canvas で描ける。

### 3.2 範囲を越える棒

- 棒は範囲の最初の日と、最後の日の終わりで切る。進みの色は、棒全体の進みの位置を同じ所で切ったものを描く。
- 前で切った棒には、範囲の左の端から 4px（`OVERFLOW_INSET_PX`）内側に `← M/D`（課題の始まりの日）を描く。
- 後ろで切った棒には、範囲の右の端から 4px 内側に右寄せで `→ M/D`（課題の最後の日）を描く。
- 字は `TextSemantic::Overflow`、色は `Note`、大きさは見出しの札と同じ。
- 切った棒は `NN%` を描かない。字は棒の端に置くので、端の一つが範囲の外にあるためである。
- 範囲の最後の日で終わる棒は切らない。

### 3.3 範囲の外の課題

- 範囲より後に始まる課題は、右の端に `→ M/D`（始まりの日）を描く。
- 範囲より前に終わる課題は、左の端に `← M/D`（最後の日）を描く。
- マイルストーンと点の形の行は、その一日が範囲の内か外かで決める。
- 当たりの区画は印の字の上に置くので、外の課題も選べる。
- 厳守の期限が範囲の日の内にあれば、外の課題でも菱形を描く。
- 範囲より前に終わる課題の添えの字は、印の右に描く。印を見えぬ棒の端に見立て、棒の字と同じく、字が厳守の菱形と重なる時だけ菱形の右へ逃がす（docs/design/bar-marks.md の 3.3）。期限を過ぎた課題の多くは、棒が既に範囲の前にあるためである。図の幅は字の右端まで延びる。字は棒の字と同じく、地の色の帯を敷いて今日の線の後の層に描く（docs/design/bar-marks.md の 3.3）。
- 範囲より後に始まる課題の添えの字は描かない。
- 行が `warn` の状態なら、印の字を `WarnStroke` の色で描く。

### 3.4 他の部品

- 依存の矢印: 矢の始まり（先の課題の棒の真ん中）か矢の先（後の課題の始まり）が範囲の外にある矢は描かない。
- 今日の線: 範囲の日の内でだけ描く。
- 進捗の線: 折れ目の x を範囲の内に留める。線の決まりの見直しは次の PR で行う。
- 厳守の菱形: 範囲の日の内でだけ描く。
- 添えの字: 切った棒では、範囲の右の端から測って置く。図の幅は字の右端まで延びる。
- 目盛り: 範囲の最後の日の次の日には線と札を描かない。札が範囲の外の日を名指すためである。
- 土日の帯: 範囲の日の内に引く。
- 群れの帯: 範囲の最後の日の終わりで止める。図の右の余白は、印と添えの字が延びる所で、帯を引かない。

## 4. 描き方

- 課題が範囲に対してどこにあるかを `Placement` 一つで求める（内に描く、前の外、後ろの外）。棒を描くのと、図の幅を決めるのと、`NN%` の札の幅を数えるのと、全てでこれを読む。
- `view` を渡さぬ時、`Placement` は全ての課題を今までの位置のまま内に描くとする。切りの計算を通らないので、既定の図の数は一桁も変わらない。
- `chart_epoch` と `chart_days` が、範囲の有る無しで最初の日と日数を決める。

## 5. 試験
