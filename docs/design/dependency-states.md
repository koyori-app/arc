# 依存の辺の状態と代わりの端の設計書

## 1. 目的

使う側（task のガント）が、依存の矢印を辺ごとの状態で描き分けられるようにする。
あわせて、端が図に無い辺（畳んだ群れの中の課題、範囲や絞りの外の課題）も、行の端や群れの見出しの行まで引けるようにする。
形は task の設計（Penpot の file『デザインシステム』の頁『ガントチャート』の板『案 A / 依存の矢印』）に沿う。

| 項 | 決め |
|---|---|
| 一、口の形 | `deps_json` の各辺に、書かずともよい鍵 `state`・`note`・`blocker_at`・`blocked_at` を足す（3.1） |
| 二、今の辺 | 鍵の無い辺は今までの形のまま描く。何も渡さぬ図の出力は変わらない（3.2） |
| 三、鍵のある辺の道 | 阻む棒の終わりの手前から下ろし、阻まれる行の中ほどで右へ折れて頭へ入る。棒の下・群れの帯の上の層（3.3） |
| 四、状態 | `normal` は `Dep`、`done` は `DepDone`、`delayed` は `DepDelayed` の破線（3.4） |
| 五、添えの字 | 阻まれる棒の右、行の添えの字の後に並べ、帯を敷く（3.5） |
| 六、代わりの端 | 群れの見出しの行の日へ引く形と、範囲の外の端まで引く形（3.6） |

## 2. 前提

- 依存は `task_relations` の blocks の向き（阻む課題 → 阻まれる課題）で受ける。
- 状態は使う側が決める。arc は課題の完了も今日との比べも知らぬ。

## 3. 設計

### 3.1 口の形

`deps_json` の各辺（`GanttDep`）に、次の鍵を足す。どれも書かずともよい。

| 鍵 | 形 | 意味 |
|---|---|---|
| `state` | `"normal"`・`"done"`・`"delayed"` | 辺の色と、`delayed` の破線 |
| `note` | 字（200 字まで） | 阻まれる棒の右に描く字（例 `REL-17 待ち`） |
| `blocker_at` | 代わりの端 | 阻む課題が図に棒を持たぬ時の始まり |
| `blocked_at` | 代わりの端 | 阻まれる課題が図に棒を持たぬ時の終わり |

代わりの端は次の二つの形のどちらかである。

- `{"row": N, "day": "YYYY-MM-DD", "label": "…"}`: 使う側の `rows_json` の N 番目（0 から）の群れの行の、その日の点。畳んだ群れの中の課題に使う。
- `{"edge": "start" | "end", "label": "…"}`: 図の左（`start`）か右（`end`）の端。範囲や絞りの外の課題に使う。

`rows_json` や `tasks_json` に足さぬ訳: 状態と添えの字は行や課題でなく辺の持ち物で、一つの課題が幾つもの辺を持つ。
代わりの端は `tasks_json` に居らぬ課題を指すので、課題の欄には置けない。

断る物（`parse_error`）:

- `note` と `label` が 200 字を越える
- `row` が `rows_json` に無い、または群れの行でない
- `day` が最初の課題から 3,650 日より離れる
- `state` の知らぬ値

### 3.2 今の辺

四つの鍵のどれも持たぬ辺は、今までの道（棒の中ほどから出る角丸の折れ線）と層（棒の上）と色（`Dep`）のまま描く。
`default_output_pin`（SVG、canvas の JSON、IR の JSON）は変わらない。

鍵のある辺が一つも無い図は、新しい層（`LayerKind::DependencyLinks`）を持たない。
新しい種（`LayerKind::DependencyLinks`、`PathSemantic::DelayedDependencyArrow`、`DrawOp::StrokeDashedPath`、色の名 `DepDone`・`DepDelayed`）は、どれも enum の末に足した。前の種の位置が変わらず、bincode の往復も今までどおり通る。

### 3.3 鍵のある辺の道

- 阻む棒の終わりから 8px（`DEP_EXIT_INSET_PX`）手前の、棒の下の縁（阻まれる行が上なら上の縁）から出る。
- 縦に阻まれる行の中ほどまで下ろし、右へ折れて、阻まれる棒の頭の 2px（`DEP_TIP_GAP_PX`）手前で止まる。
- 阻まれる棒が出る所より前に始まる時は、阻まれる行の上の境（上へ向かう時は下の境）まで下ろし、頭の 12px（`DEP_DETOUR_PX`）左まで戻ってから、行の中ほどへ下りて入る。日の食い違いが形で分かる。
- 角は半径 4px（`DEP_CORNER_PX`）で丸める。脚が短い角は、脚の半分まで小さくする。
- 道の全ての点は x = 0 以上、図の幅以下に収める。図の幅は、添えの字に加え、鍵のある辺の道の点・矢じり・字の帯の実の置き場から求める（阻む側と阻まれる側の両方。描く道と同じ求め方を使うので、幅と描いた物が食い違わない）。SVG と canvas は同じ表示の一覧を描くので揃う。
- 線は群れの帯の上・棒の下（`LayerKind::DependencyLinks`、棒の層の直前）に描き、通り道の棒を隠さない。
- 太さは 1.5px。矢じりは今の辺と同じ開いた山形。
- 阻む課題と阻まれる課題が同じ行の辺は描かない。

### 3.4 状態

| 状態 | 色の名 | 線 |
|---|---|---|
| `normal`（と、`state` の無い鍵のある辺） | `Dep` | 実線 |
| `done` | `DepDone`（落ち先は `Dep`） | 実線 |
| `delayed` | `DepDelayed`（落ち先は `Dep`） | 破線 `4,3` |

`DepDone` と `DepDelayed` は既定の色の表に入れず、落ち先を `Dep` にした。palette を渡さぬ図は、どの状態も今の矢印の色で描く。
canvas の色の番号は `DepDone` が 25、`DepDelayed` が 26。破線は SVG で `stroke-dasharray`、canvas で `DrawOp::StrokeDashedPath` にする。

### 3.5 添えの字

- `note` は阻まれる棒の右に、行の添えの字（docs/design/bar-marks.md）の後に置く。行の添えの字が無ければ、行の添えの字が来る所に置く。
- 一つの棒が幾つもの辺の添えの字を持つ時は、辺の順に、字の幅の見積もりと `NOTE_GAP_PX` だけ空けて並べ、重ならせない。
- 添えの字が厳守の期限の菱形に掛かる時は、行の添えの字と同じく、菱形の右へ退く。退くかは、その添えの字の幅で決める。行の添えの字が既に菱形を越えていれば、辺の添えの字はその後に続き、もう一度は退かない。
- 字の下に、行の添えの字と同じ地の色の帯（`NoteBg`）を敷く。字の色は辺の色（`delayed` なら `DepDelayed`）。
- 図の幅は、辺の添えの字の右端まで延びる。描く所と幅は同じ見積もりを読む。

### 3.6 代わりの端

- 行の点（`row`・`day`）: その行の中ほど、その日の左の x を、棒の代わりの点とする。終わりなら道はそこへ右へ入り、`label` を矢じりの右に描く。始まりなら点から出て、`label` を点の右上に描く。
  - view を渡さぬ図では、行の点の日を図の日の範囲に含める。課題の日と同じく、最初の課題より前の日なら図の始まりを、全課題の終わりより後の日なら図の終わりを広げる。
  - view を渡した図で、行の点の日が view の映す日の外なら、その側の端（`edge` の `start` か `end`）と同じに扱う。点ではなく図の端まで引き、`label` は端に描く。
- 端（`edge`）: 図に在る端の行の中ほどを、図の端まで引く。阻まれる課題が外なら矢じりは端に向き、`label` を端の手前（`end` は右寄せ）、線の上に描く。阻む課題が外なら端から入り、`label` を端の内側、線の上に描く。
- どちらの `label` も地の色の帯を敷き、辺の色で描く。

## 4. 確かめ

- `tests/dependency_states.rs`: 鍵の無い辺が今の形のまま、状態の色と破線（SVG と canvas）、棒の下の層、道の形（出る所・折れる所・入る所、食い違いの回り込み）、添えの字の並びと色と帯、群れの見出しの行と端の代わり、範囲より前と後の日の行の点（view の有無、両側、字の有無）の全ての点が x = 0 以上で図の幅以下、図の日に入ること、阻む側の長い字が欠けないこと、幅、断り
- `default_output_pin`、bincode の往復（`display_list_tests`）
- arc-vue `dependencyStates.wasm.test.ts`: 本物の wasm の SVG と canvas の状態の色と破線、canvas の再生の破線と色の落ち先
