# 棒の形と印の設計書

| 項目 | 値 |
|------|-----|
| 文書ID | `design/bar-marks` |
| 関連 | `design/day-scale`（この上に積む）、`design/external-rows`、task の cmd_411（ガントの作り直し） |
| 状態 | 実装 |
| 基準 | `feat/gantt-scale` の `b6703be` |

## 1. 要約

使う側が並べた課題の行（`rows_json`）に、印を持たせられるようにする。

- 厳守の期日の菱形
- 状態による棒の塗りと縁（通常、済み、警告）
- 棒の右の添えの字
- 予定開始の無い課題を、棒ではなく最後の日の点で描く形

task のガントは、目安と厳守の二つの期日、警告の縁と字、期間の無い課題の置き方を求める（cmd_405 の困り所の二、三、五）。
期日と状態は課題そのものではなく、使う側が行に添える見せ方なので、`tasks_json` ではなく `rows_json` の課題の行に持たせる。

| 問い | 採る答え |
|------|---------|
| 一、厳守の期日 | 課題の行の `hard_deadline`（`YYYY-MM-DD`）。その日の欄の真ん中に菱形（3.1） |
| 二、状態 | `state`: `"normal"`、`"done"`、`"warn"`。棒の地の色と縁の色を決める（3.2） |
| 三、添えの字 | `note`。棒と菱形の右に一行。200 字まで（3.3） |
| 四、点の形 | `shape`: `"bar"`（既定）か `"point"`。期間の最後の日の真ん中に点。後ろに菱形があれば線で結ぶ（3.4） |

印を一つも持たぬ行は、今までの課題の行と一字も違わない図になる。`rows_json` を渡さぬ図も変わらない。

範囲の外へ続く印（表示の範囲の端で棒を切り、`→ M/D` を添える）は、表示の範囲を選ぶ口と合わせて次の PR に分ける。

## 2. 今の作りで確かめたこと

- 課題の行は `task_id` と `height` だけを持つ。行の一覧の読みは `render.rs` の `parse_rows_json` にあり、知らぬ鍵は断る。
- 棒は灰の地（`BarBg`）に、進みの割合の幅だけ段の色を重ねる。縁は描かない。
- 図の幅は最後の課題の終わりと、札の右端で決まる。

## 3. 口の形

課題の行 `{"kind":"task","task_id":…}` に、次の鍵を足す。どれも省ける。値が `null` の鍵は、その鍵が無いのと同じ。

### 3.1 `hard_deadline`

- `YYYY-MM-DD`。その日の欄の真ん中を中心に、幅と高さが 10px（`HARD_DEADLINE_HALF_PX` の二倍）の菱形（`PolygonSemantic::HardDeadline`、class `hard-deadline`）を描く。
- 最初の課題の始まりより前の日は描かない（図の左の外になるため）。
- 最後の課題の終わりより後の日は、図の日数を延ばして菱形を図に収める。
- 最初の課題の始まりから 3,650 日（`MAX_DATE_SPAN_DAYS`）より離れた日は `parse_error` で断る。課題の日付と同じ上限である。

### 3.2 `state`

| 値 | 地 | 縁 |
|----|----|----|
| `normal` | `BarBg` | `BarStroke` |
| `done` | `DoneBg` | `DoneStroke` |
| `warn` | `WarnBg` | `WarnStroke` |

- `state` を書いた行だけ、棒の上に角の丸い縁（`PathSemantic::BarOutline`、幅 1px）を引く。書かぬ行は今まで通り縁が無い。
- 進みの割合の色（段の色）は状態で変えない。

### 3.3 `note`

- 棒（点）の右端から 6px（`NOTE_GAP_PX`）右に、見出しの札と同じ大きさで一行描く（`TextSemantic::BarNote`）。字は棒に係るので、棒の右に置く。
- 字が厳守の菱形と重なる時だけ、菱形の右端から 6px 右へ逃がす。重なりは、字の左右の端（字の幅は見出しの札と同じ見積もり）と菱形の左右の端で測る。菱形が棒の上にある時と、字の右端より遠い時は、棒の右のまま。
- 点の行は、点から後ろの菱形へ引く線も菱形と同じく字の邪魔になる。点の右の字が点から菱形の右端までに掛かる時は、菱形の右へ逃がす。
- 置き場は前の版では「棒と菱形の遠い方の右」であった。棒から離れた字が、どの棒の字か読みにくくなるので改めた（task の cmd_411 の判じ）。
- 色は `warn` の行で `WarnStroke`、他は `Note`。
- 字の下に、図の地の色の淡い帯（`RectSemantic::NoteBackground`、class `note-bg`、色の名 `NoteBg`）を敷く。帯は字の幅の見積もりの左右に `NOTE_BAND_PAD_PX`（2px）ずつ足した幅で、図の幅は変えない。
- 帯と字は、行の束でなく、今日の線の後に描く層（`LayerKind::Notes`）に入れる。今日の線と格子は字の所だけ帯に隠れ、字が読める。置き場は変えない。添えの字を持つ行が一つも無い図には、この層が無い（印の無かった頃の図と同じ）。
- 字は他の字と同じく escape して書く。
- 図の幅は字の右端まで延ばすので、字が図からはみ出さない。
- 200 字（`MAX_NOTE_CHARS`）を越える字は `parse_error` で断る。

### 3.4 `shape`

- `"point"` の行は棒を描かず、期間の最後の日の真ん中に、棒の高さの半分の径の点（`RoundRectSemantic::Point`、class `bar-point`）を描く。期間が 0 日の課題は始まりの日に描く。
- 点の色は縁の色（3.2）。
- 菱形が点より右にあれば、点から菱形の中心へ線（`LineSemantic::DeadlineLink`）を引く。
- task は予定開始の無い課題を、期日の一日の課題として渡し、`"point"` で描く。

### 3.5 色の名

色の名を八つ足した。どれも既定の色の表には入れず、落ち先の色で描く（`palette` で替えられる）。既定の色の表は出力を縛る試験に含まれるので、表に足すと全ての出力が変わるためである。

| 名 | 落ち先 | canvas の色の番号 |
|----|--------|-----|
| `BarStroke` | `GridLabel` | 15 |
| `DoneBg` | `BarBg` | 16 |
| `DoneStroke` | `GridLabel` | 17 |
| `WarnBg` | `BarBg` | 18 |
| `WarnStroke` | `Progress` | 19 |
| `HardDeadline` | `Progress` | 20 |
| `Note` | `GridLabel` | 21 |
| `NoteBg` | `HeaderBg` | 22 |

## 4. 描き方

- 印の位置（点の中心、菱形の中心、字の始まり）は `MarkGeometry` 一つで求める。描くのと幅を決めるのと両方でこれを読むので、字と菱形が図の外へ出ない。
- 点の半径は `point_radius`（棒の高さの四分の一）一つで決め、点を描く所と、点の行の字の始まり（点の右端から `NOTE_GAP_PX`）を決める所が共に読む。一日の幅は点の大きさに関わらない。棒を高くしても、日を広げても、字は点の右から始まる。
- 図の日数は `span_days` で、最後の課題の終わりと、行の厳守の期日の遅い方まで。
- 縁は相対の弧（`a`）で書き、他の path と同じ命令だけを使う。
- `rows.rs` の `Slot` に、行の一覧の何番目の行かを持たせ、描く時に行の印を引く。

## 5. 試験

- `display_list/marks_tests.rs`: 印の無い行は今までの図と同じ。状態の地と縁の色と落ち先。菱形の位置。後ろの期日で図が広がる。前の期日は描かない。点の位置と期限への線。字の位置と図の幅。字の置き場（重ならぬ時は棒の右、重なる時は菱形の右、菱形の無い行は棒の右、菱形が棒の上の時は棒の右、点の行は線と菱形の右）。棒の高さと一日の幅が違う形（棒 120・一日 30、棒 10・一日 60）で、点の行の字が点の右端から始まり、菱形とも重ならぬこと。
- `tests/bar_marks.rs`: 印の無い一覧は `rows_json` の無い図と同じ。印の読み。断る値（知らぬ状態と形、読めない日付、長い字、遠い期日）。字の escape。棒 120・一日 30 の点の行の字が、SVG と canvas で同じ所（点の右端から NOTE_GAP_PX）に描かれること。
- arc-vue: `palette.test.ts`（印の色の落ち先）、`marks.wasm.test.ts`（本物の wasm）。
- Storybook: `BarMarks`、`BarMarksCanvas`。
